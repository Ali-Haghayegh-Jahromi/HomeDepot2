# Sample photo

`deck_board.jpg` is a placeholder for testing the photo step: a timber deck with some new boards (some
boards already replaced). It shows no crack or split, so the AI describes new boards, not damage. It is
fine for testing, not for the recording: photograph a real cracked or split board (or another real broken
item) for that.
